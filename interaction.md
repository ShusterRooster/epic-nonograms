## keyboard:
* z - fill highlighted tile
* x - cross highlighted tile
* shift + arrow key - select multiple blocks
  * unpressing shift will deselect
  * pressing fill or cross buttons while having a selection will do the corresponding action

## mouse/touch:
* `z` - toggle fill mode
* `x` - toggle cross mode
* clicking on a tile will do the action that is currently enabled
* dragging on tiles will do the action on selected tiles unless cancelled


* `Shift + z` - starts keyboard drag operation
  * when done with selection: 
    * `Shift + z` again to cancel drag selection
    * `z` to fill it

## d-pad:
* must use action buttons to enact action, no toggling
* when dragging on d-pad, it will act like dragging on the selected tile with your finger, used to create selections and measure tiles with ease
